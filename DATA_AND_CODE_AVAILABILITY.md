# Data and code availability

## Current public availability

The partial reproducibility package is publicly available at
https://github.com/skynmwoo/military-persona-survey.

It includes the fixed persona samples, locked analysis plan and separate
hard-choice protocol, prompts and analysis code, analysis-ready model outputs,
the transcribed human-survey benchmark, and final analysis tables. It excludes
model weight files, the complete Nemotron-Personas-Korea source dataset, and
the complete local execution environment. Links to the source dataset and
models and the recorded implementation requirements are provided in this
repository. Re-executing Motif 3 requires separate access to the external API.

## Current manuscript wording

고정 표본, 분석계획, 프롬프트·분석 코드, 분석용 모델 출력과 결과표를 GitHub의 부분 재현 패키지(https://github.com/skynmwoo/military-persona-survey)에 공개하였다. 모델 가중치와 전체 NPK 데이터셋·실행환경은 포함하지 않는다.

## Scope note

The repository supports inspection of the actual experimental implementation
and reproduction of the released analyses. It is not a turnkey release of the
complete experimental environment or a claim that future model or API
executions will return byte-identical responses. The probability-based Primary
analysis and the separate post-lock hard-choice study retain their distinct
research status. Representative Motif results are not selected by human-survey
agreement.
